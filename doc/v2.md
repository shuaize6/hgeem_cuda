# v2：2×2 寄存器分块

## 相比 v1 改了什么

线程数不变，输出 tile 从 16×16 增到 32×32，BK 仍为 16。每线程维护四个 float 累加器 `c00/c01/c10/c11`，shared 为 A[32][16] 和 B[16][32]，共 2 KiB。

## 2×2 的准确含义

这是输出坐标间隔 16 的 2×2，不是相邻四个元素：

```cpp
row0 = blockIdx.y * 32 + ty;
row1 = row0 + 16;
col0 = blockIdx.x * 32 + tx;
col1 = col0 + 16;
```

线程 `(3,2)` 在第一个 block 中计算 `C[2,3]`、`C[2,19]`、`C[18,3]`、`C[18,19]`。

## 数据如何流动

每线程合作加载两份 A、两份 B。barrier 后，对每个 k 读取 `a0,a1,b0,b1`，然后做外积：

```cpp
c00 += a0*b0; c01 += a0*b1;
c10 += a1*b0; c11 += a1*b1;
```

4 次 shared 元素读取支持 4 次乘加，平均每次乘加 1 次读取；v1 是 2 次读取。这是源代码层面的复用量，不直接等于硬件访存事务数。

K 循环尾部的第二个 barrier 仍然保护 shared buffer；四个输出分别检查边界。因此 M/N 为奇数或 tile 越界时，一个线程可以只写其四个输出中的一部分。

## 代价与继续优化

寄存器累加器从 1 个增到 4 个，shared 也增大。v3 沿同一思路增到 16 个累加器，继续减少单位乘加需要的 shared 读取；最终效果还要看资源占用。
